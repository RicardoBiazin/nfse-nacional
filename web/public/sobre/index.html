NFS-e Nacional

Emissor de NFS-e Nacional grátis e de código aberto

O NFS-e Nacional é um programa para emitir e consultar a NFS-e do Padrão Nacional direto nas APIs do governo, sem provedor intermediário: a emissão vai para a Sefin Nacional e as notas emitidas e recebidas chegam pelo ADN (Ambiente de Dados Nacional).

A API de DANFSe do governo foi suspensa pela NT 008/2026. Por isso o programa gera o DANFSe localmente, no layout da nota técnica, e esta versão para navegador faz o mesmo a partir do XML da nota, sem enviar o arquivo a ninguém.

O leiaute usado é o da DPS 1.01 (XSD oficial de 09/02/2026, com o grupo IBS/CBS opcional). O programa começa em Produção Restrita, o ambiente de testes; a produção só é usada por escolha explícita no cadastro da empresa.

Recursos

  • Emissão direta na Sefin Nacional: DPS assinada com o seu certificado A1, consulta por chave e por Id da DPS, cancelamento (evento 101101) e parâmetros municipais.
  • Notas emitidas e recebidas: distribuição por NSU no ADN, com os eventos de cancelamento e substituição.
  • DANFSe em PDF no programa e no navegador, com a marca "CANCELADA" ou "SUBSTITUÍDA" quando o XML do evento vem junto; vários XMLs ou um .zip de uma vez.
  • Consulta de códigos: lista de serviços nacional (código de tributação), NBS 2.0 e municípios IBGE.
  • Consulta de CNPJ e CEP no cadastro do tomador e envio da nota por e-mail pelo SMTP da própria empresa (programa para Windows).
  • Versão para a rede da empresa: um computador vira servidor e as pessoas usam pelo navegador, com login, permissões e auditoria.

Perguntas frequentes

O NFS-e Nacional é gratuito?

Sim. É um programa gratuito e de código aberto, sob a licença AGPL-3.0. O código está no GitHub.

Posso emitir a nota pelo navegador?

Não. Emitir exige o certificado digital A1 e uma conexão mTLS com a Sefin Nacional, por isso a emissão só existe no programa instalado para Windows. No navegador você gera o DANFSe a partir do XML e consulta os códigos.

O XML da nota é enviado para algum servidor?

Não. O site não tem banco de dados nem recebe arquivos: o XML é lido e o PDF do DANFSe é gerado pelo seu próprio navegador.

Por que gerar o DANFSe aqui e não no site do governo?

A API de DANFSe do Ambiente de Dados Nacional foi suspensa pela NT 008/2026. O NFS-e Nacional gera o DANFSe localmente, no layout do Anexo I dessa nota técnica.

Onde fica o meu certificado digital?

Só no seu computador. No programa para Windows o arquivo .pfx fica na pasta de dados local e a senha no Cofre de Credenciais do Windows. Ele nunca vai para o repositório nem para o executável.

Este é um site do governo?

Não. É um projeto independente que usa as APIs públicas do Sistema Nacional NFS-e (Sefin Nacional e ADN), sem provedor intermediário.
